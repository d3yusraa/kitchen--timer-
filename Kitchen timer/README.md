
# Kitchen Timer 🍳

A simple, responsive countdown timer built for the
MetaBox Internship Hackathon.

## Features

- Custom countdown in minutes and seconds
- Start, Pause, Resume, and Reset controls
- Quick presets:
  - 3 minutes for tea
  - 10 minutes for rice
  - 20 minutes for cooking
- Sound notification when the timer finishes
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Deployment

Deployed using Vercel.
